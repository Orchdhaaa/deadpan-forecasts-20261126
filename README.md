One deadpan weather forecast for a city that does not exist: "In Nulverton, light rain of unsent letters falls until noon, clearing to 21 degrees and a 40 percent chance the postman finally answers." Straight-faced broadcast tone until the absurdity lands: the rain is undelivered mail, and the forecast ends on the postman finally answering.

## Run it

```sh
node main.ts
```

`main.ts` writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single sentence of 1–160 characters with no dash.
